# Cookie 偏好功能

用户于 2026-10-18 确认以下方案。保持纯静态，无后端、数据库或地区识别；中英页面使用一致规则。

## 交互与用途

- 初次访问显示底部横幅，正文可继续浏览。“接受全部”为突出主按钮，同时提供“仅必要”和“自定义设置”。页脚始终提供重新打开设置的入口。
- 必要存储仅记住 Cookie 偏好，始终启用；访问分析使用 GA4，首次打开自定义面板时默认关闭。当前没有广告追踪类别，“接受全部”不会开启广告信号。
- 自定义面板采用原生 dialog，支持键盘焦点约束、Escape 关闭和焦点返回；关闭或 Escape 不保存临时选择。关闭已启用的访问分析会刷新页面，面板中有对应说明。
- 通过必要本地存储 `ggeo-cookie-preferences` 保存版本、分析选择和到期时间，期限为 180 天，在同一浏览器、同一来源的中英页面共享。清除浏览器数据、偏好失效或到期后重新询问。变更追踪用途时应升级偏好版本并重新征求选择。
- 存储不可用时不默认同意。主动选择仅在当前页面内存中生效，并显示提示；之后重新访问会再次询问。

## 统计控制

采用 Google 基本同意模式：未选择、仅必要或已到期时，不加载 Google 标签，不向 Google 发送分析请求。已同意时仅生产主机名的内容页加载一次 GA4，本地、预览域名及根目录跳转均排除。

撤回时先启用 GA 停用标志，再清理可访问的第一方 `_ga`、`_ga_*`、`_gid`、`_gat`、`_gat_*` Cookie 并刷新页面，卸载旧统计代码及监听器。拒绝状态也会清理旧版留下的这些 Cookie。不同标签页通过 storage 事件同步，恢复页面及有效期届满时重新检查偏好。不会删除其他用途的 Cookie，也无法删除已经发给 Google 的历史数据。

## 验证与发布状态

`npm run validate`、`npm run build` 和 `npm test` 均通过，13 项测试覆盖偏好状态、统计阻断与启用、撤回、存储异常、静态页面及 HTTP 行为。HTTP 测试需要允许回环网络监听。

浏览器已检查英文首页、中文首页与中文隐私页，验证初始选项、关闭不保存、自定义保存、拒绝、跨语言记忆、页脚重开及 390px 移动端布局；本地没有 Google 统计请求或浏览器脚本错误。生产域名启用与撤回通过隔离的代码测试验证，没有向线上站点发送测试访问事件。英文设置面板的自动无障碍检查没有报告违规，颜色对比仍结合截图人工检查。

当前未发布至线上。构建生成 84 个 HTML 页面；正文、canonical、hreflang 与结构化数据保持静态可读取。

实现依据：[Google 同意模式](https://developers.google.com/tag-platform/security/concepts/consent-mode)、[GA 停用标志](https://developers.google.com/tag-platform/security/guides/privacy)、[Google 搜索弹窗指南](https://developers.google.com/search/docs/appearance/avoid-intrusive-interstitials)。180 天是已确认的产品期限，不代表法律强制期限。
