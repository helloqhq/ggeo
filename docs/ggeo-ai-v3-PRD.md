# ggeo.ai — GEO 工具导航网站需求文档（PRD V3.0）

> **版本：** V3.0  
> **产品形态：** 垂直 GEO 工具导航 / 目录网站  
> **默认语言：** 英文（English），支持简体中文  
> **核心目标：** 获取 Google 等搜索引擎的自然搜索流量，通过联盟营销、展示广告和赞助推广变现  
> **视觉基调：** 深色专业科技风（以最后确认的深色原型为准）  
> **文档状态：** 可用于 UI 设计、前端开发和内容录入的初版需求

## 1. 项目概述

### 1.1 产品定位

**ggeo.ai** 是专注于 **GEO（Generative Engine Optimization，生成式引擎优化）** 的工具导航网站，帮助 SEO 从业者、营销人员、独立站站长、企业品牌和营销代理机构发现、筛选和比较 AI 搜索曝光相关工具。

网站只收录与 GEO / AI Search Visibility 直接相关的工具，**不扩展为泛 AI 工具导航站**。不以自研 GEO 监控 SaaS 为第一阶段目标。

**英文品牌文案：**
- 主标题（H1）：`Best GEO Tools Directory`
- 副标题：`Discover and compare AI search visibility tools.`
- 品牌简介：`Discover the best GEO tools.`

### 1.2 商业目标

1. **SEO 流量优先：** 首页、分类页、工具详情页均支持独立收录与关键词布局。
2. **工具发现效率：** 访问首页即可看到分类及对应工具入口，减少点击层级。
3. **联盟变现：** 引导用户从工具详情页访问第三方工具官网或产品注册页。
4. **广告变现：** 在不干扰浏览的前提下部署展示广告与赞助位。
5. **长期内容资产：** 通过真实工具资料、实测信息、持续更新和合理内链积累搜索价值。

### 1.3 目标用户

- 英语市场的 SEO / GEO 从业者和独立站站长
- 企业营销人员、增长团队、品牌负责人
- SEO / 数字营销代理机构
- 想对比 AI 搜索可见性产品的开发者及 SaaS 团队
- 中文市场的相关从业者（中文版本）

### 1.4 产品原则

- **垂直：** 仅 GEO 相关工具。
- **紧凑：** 顶部分类单行排列，工具列表是首页主体。
- **可信：** 使用真实工具、真实官网与可核实的信息；不伪造评分、用户量、排名增长和价格。
- **可收录：** 重要页面拥有可访问的固定 URL、独立元数据和服务端可读取的内容。
- **商业透明：** 清楚标记广告、赞助和联盟链接。

## 2. 站点信息架构

```text
ggeo.ai/
├── en/                              # 英文首页（默认）
│   ├── category/{category-slug}/    # 英文分类页
│   ├── tools/{tool-slug}/           # 英文工具详情页
│   ├── search/?q=...                # 英文站内搜索结果页
│   ├── submit/                      # 工具提交页
│   ├── privacy-policy/              # 隐私政策
│   ├── disclaimer/                  # 免责声明
│   ├── contact/                     # 联系我们
│   └── partner-links/               # 友情链接
└── zh/                              # 中文首页
    ├── category/{category-slug}/
    ├── tools/{tool-slug}/
    ├── search/?q=...
    ├── submit/
    ├── privacy-policy/
    ├── disclaimer/
    ├── contact/
    └── partner-links/
```

- `/` 可指向默认英文站 `/en/`，但应保持搜索引擎能稳定访问两个语言版本；不要根据 IP 强制重定向所有访问。
- 英文和中文的分类、工具页面使用**相同稳定 slug、不同语言前缀**。
- 语言切换时优先留在相应内容页：例如 `/en/tools/otterly-ai/` ↔ `/zh/tools/otterly-ai/`。
- 未提供对应翻译时，回退到对应语言首页或明确提示，不生成无实际翻译内容的重复页。

### 3.1 顶部导航 Header

- 左侧：`ggeo.ai` 品牌 Logo，点击返回当前语言首页。
- 右侧：`All Tools`、`Submit`、`EN / 中文`。
- `All Tools`：进入全部工具列表；首期可先定位至首页工具目录区域，后续提供独立列表页。
- `Submit`：进入工具提交页，由管理员审核后发布。
- 语言切换：英文与简体中文两项，当前语言清晰高亮。
- 页面滚动时可选择使用紧凑型吸顶导航，但不得遮挡锚点定位后的分类标题。

### 3.2 单行分类入口

- **桌面端只占一行**，采用紧凑文字 Tab / Pill，不显示大图标和长描述。
- 点击顶部分类，滚动到首页对应分类区域（如 `#ai-visibility`）。
- 移动端保持单行、允许横向滚动，**不换成两行分类卡片**。
- 分类顶部菜单与正文分类区域采用完全一致的顺序。
- 当前定位分类和 Hover 状态使用青蓝主色强调。

### 3.3 Hero + 搜索区

- 采用紧凑型首屏引导，禁止大面积仪表盘、统计大图或冗长营销文案。
- 内容：H1、副标题、一个大搜索框、简短辅助说明。
- 搜索范围：工具名称、英文/中文介绍、分类和功能标签。
- 回车和 Search 按钮均可提交；结果显示工具卡片及所属分类。
- 搜索无结果时显示明确提示，允许返回分类浏览。
- 不将每一种搜索词结果生成可索引的低质量页面。

### 3.4 分类工具区

每个分类模块包括：

1. 分类标题及简洁图标。
2. `View All →`：进入当前语言对应的独立分类页。
3. 工具卡片列表：桌面端每行 **3 张卡片**，首页优先显示 **3–6 个精选工具**；可根据内容量选择展示一行或两行。
4. 分类间用适量留白与细分隔线区分，不插入无意义视觉装饰。

分类按照文档第 4 节的固定顺序展示。若某分类还没有足够的真实工具，允许暂时减少卡片数量或延后公开其分类落地页，**不得用虚构工具凑数**。

### 3.5 工具卡片

卡片必须包含：

| 字段 | 说明 |
|---|---|
| Logo | 产品真实 Logo；缺失时使用中性字母占位 |
| 工具名称 | 清晰可点击，跳转本站详情页 |
| 简介 | 1–2 行，描述核心 GEO 功能 |
| 功能标签 | 最多 3 个，避免标签堆砌 |
| 价格模式 | `Free` / `Freemium` / `Paid` / `Contact Sales` / `Unknown` |
| 操作入口 | `View Details →`，进入详情页 |

- 不展示未经验证的评分、评论数、用户数、增长率等。
- 首页默认展示本站详情入口；第三方产品官网、联盟链接主要放在详情页。
- 广告或赞助工具必须有明确的赞助标识。

### 3.6 广告与赞助区

- 广告以横向区块形式穿插在部分分类之间，建议先在 **Citations 之后、GEO Audit 之后**各预留一处。
- 未接入广告时可不显示，避免空广告块影响浏览。
- 广告必须有 `Advertisement` / `Sponsored` 标签，与自然分类结果区分。
- 广告版位尽量保持固定或预留空间，避免加载后产生明显布局跳动。
- 不得在广告素材中宣称未经证实的访问量或广告效果。

### 3.7 页脚 Footer

英文版提供以下链接，中文版显示对应中文文本：

| 英文 | 中文 | 作用 |
|---|---|---|
| Privacy Policy | 隐私协议 / 隐私政策 | 数据与 Cookie 说明 |
| Disclaimer | 免责声明 | 第三方产品信息、联盟关系声明 |
| Contact Us | 联系我们 | 联系表单或明确的联系渠道 |
| Partner Links | 友情链接 | 行业合作与相关高质量网站 |

此外包含品牌 Logo、简短品牌说明、当前语言、版权信息。

## 4. GEO 分类体系

| 顺序 | 英文菜单名称 | 中文菜单名称 | Slug | 主要工具方向 |
|---|---|---|---|---|
| 1 | AI Visibility | AI 曝光监控 | `ai-visibility` | AI 搜索可见性、品牌提及监控 |
| 2 | Citations | 引用追踪 | `citations` | AI 回答中的引用来源监控 |
| 3 | Prompts | 提示词监控 | `prompts` | Prompt 研究、提问词监测 |
| 4 | Competitors | 竞品分析 | `competitors` | 竞品曝光、Share of Voice |
| 5 | GEO Audit | GEO 诊断 | `geo-audit` | AI 爬虫、可抓取性、站点诊断 |
| 6 | Content GEO | GEO 内容优化 | `content-geo` | 面向 AI 搜索的内容优化 |
| 7 | AI Traffic | AI 流量分析 | `ai-traffic` | AI 来源流量与归因分析 |
| 8 | Local GEO | 本地 GEO | `local-geo` | 本地企业的 AI 搜索曝光 |

**归类规则：** 每个工具有 1 个主要分类，可附加多个功能标签；只有具备明确对应能力时才允许加入其他分类，避免同一工具在首页过度重复。

## 5. 页面功能需求

### 5.1 分类详情页

- 独立 H1、简短分类介绍、工具列表和分类说明。
- 工具按人工精选排序，后续可增加价格类型和功能标签筛选。
- 每个工具条目直接链接到本站对应语言的工具详情页。
- 页面底部可提供相关分类导航，但不能生成空泛、机械重复的 SEO 内容。

### 5.2 工具详情页

至少包含：

1. 工具名称、Logo、简介、主要分类和功能标签。
2. 支持的 AI 搜索平台或适用场景（仅展示已核实内容）。
3. 功能概述、适用人群、价格模式和官网链接。
4. 优点、局限性及替代产品（有可靠信息时展示）。
5. 信息来源、最后核验/更新时间。
6. `Visit Website` / `Try Tool` 主按钮；存在联盟关系时按要求披露。

不得照搬厂商页面作为整页详情；重点产品逐步补充原创对比、实测体验与截图。

### 5.3 工具提交

- 公开表单字段：工具名称、官网 URL、类别、简短描述、提交者邮箱（可选或按反垃圾策略要求）。
- 表单有反垃圾验证、重复 URL 检查和管理员审核流程。
- 新提交工具默认**未发布**，审核通过后才进入目录。

### 5.4 后台内容管理

管理员需要支持：
- 新增、编辑、隐藏、发布工具。
- 维护英文/中文名称与介绍、Logo、价格模式、标签及主要分类。
- 配置首页精选排序和工具是否显示。
- 更新官网地址、联盟 URL、内容核验时间。
- 管理分类介绍、页脚页面和广告位配置。
- 审核用户提交内容。

## 6. 中英文国际化（i18n）

- 英文为默认语言；右上角始终提供 `EN / 中文` 切换。
- 全站统一翻译导航、分类、按钮、搜索提示、页脚和工具介绍。
- 中英文页面分别提供独立的 `title`、`meta description`、H1 和正文。
- 同一内容的两个语言 URL 互相声明 `hreflang="en"`、`hreflang="zh-CN"`，并正确设置自引用 canonical；根据部署情况配置 `x-default`。
- URL 不因用户所处国家、IP 或 Cookie 而变得不可访问；用户可明确切换语言。
- 未翻译的页面不应简单复制英文内容并标为中文，避免低质量重复内容。

## 7. SEO 需求

### 7.1 页面级基础 SEO

- 采用 SSR / SSG 或其他可以向爬虫直接输出完整主要内容的方案。
- 每个可收录页面有唯一、准确的 Title、Description、H1 和语义化标题层级。
- 使用真实 `<a href>` 作为主要内部导航链接。
- 配置 XML Sitemap、`robots.txt`、canonical 和 404 状态处理。
- 首页 → 分类页 → 工具详情页之间形成清晰内链。
- 站内搜索结果页原则上 `noindex,follow`，避免生成无限搜索结果索引页。
- 基于真实信息使用 `Organization`、`WebSite`、`BreadcrumbList`、`ItemList` 等适当结构化数据；工具数据符合要求时可使用 `SoftwareApplication`，不能虚构 rating / review / price。

### 7.2 内容策略

- 优先收录真实且相关的 GEO 工具，不使用模型批量捏造产品资料。
- 每个分类页有独特的选型价值、适用场景与工具差异信息。
- 详情页突出原创补充信息，如优缺点、支持平台、实测结果或价格核验时间。
- 后续可以扩展“最佳免费 GEO 工具”“产品 A vs 产品 B”等专题页面，但**不属于 V3.0 首页必需模块**。
- 不承诺上线即可取得搜索排名或流量。

### 7.3 衡量指标

- Google Search Console：有效收录页面、自然搜索曝光、自然点击、主要查询词。
- 网站分析：分类点击率、站内搜索使用率、工具详情访问率、官网跳转率。
- 商业指标：联盟点击量、有效转化、广告填充率、广告收入（实际接入后统计）。

## 8. 视觉设计规范（当前确认版）

**采用最新确认的深色专业科技风，替代 V3.0 文字阶段曾建议的浅色方案。**

| 设计元素 | 建议值 / 原则 |
|---|---|
| 页面主背景 | 黑蓝 / 深灰蓝，例如 `#081426` |
| 卡片背景 | 略亮的深蓝灰，例如 `#102039` |
| 主色 | 青蓝，例如 `#22B8F0` / `#168BFF` |
| 辅色 | 紫色渐变，例如 `#6D4CFF` |
| 重点点缀 | 少量荧光绿，例如 `#39D9A3`，仅用于状态/积极反馈 |
| 标题文字 | 近白色，例如 `#F5F8FF` |
| 次级文字 | 蓝灰，例如 `#A7B8D0` |
| 分割线 | 低对比度深蓝边框 |
| 字体 | Inter、Geist 或同类无衬线字体；中文使用兼容的系统无衬线字体 |
| 内容最大宽度 | 约 `1280px`，左右保持合理边距 |
| 卡片圆角 | 约 `10–12px` |

设计原则：**可信、专业、清晰优先于炫酷特效**。仅在 Hero、当前分类和少量 CTA 使用克制的蓝紫渐变/微弱发光；正文不使用大面积动画、星空装饰或大型数据仪表盘。卡片文字对比度应优先保证可读性。

## 9. 响应式与性能

| 设备 | 布局 |
|---|---|
| 桌面（约 ≥1200px） | 工具卡片每行 3 张；分类入口尽量单行展示 |
| 平板 | 卡片每行 2 张；分类入口允许横向滚动 |
| 手机 | 卡片每行 1 张；顶部分类始终单行横滑；Header 简化但保留语言切换 |

- 搜索栏宽度随视口变化，按钮保持可点击。
- 图片优先采用轻量尺寸，Logo 懒加载并保留尺寸占位。
- 控制 Core Web Vitals，工程目标可参考 LCP ≤ 2.5s、INP ≤ 200ms、CLS ≤ 0.1（以真实用户数据评估）。
- 键盘可操作导航、可见焦点、可读对比度、明确的链接名称。

## 10. 商业化与合规要求

### 10.1 联盟营销

- 联盟链接统一由后台维护，不在工具资料中硬编码。
- 联盟链接使用适当的 `rel="sponsored"`，新窗口打开时补充安全属性。
- 详情页或合适位置提供清晰、简短的联盟关系披露。
- 产品排序不默认按佣金高低决定；如有付费优先展示，必须标明赞助。

### 10.2 广告

- 支持横幅式展示广告、赞助工具位、后续直客合作。
- 广告需要明显的 `Advertisement` 或 `Sponsored` 标记。
- 优先保证主要目录内容可见；不要用广告把分类列表隔得过于零散。
- 接入广告及分析服务时，隐私政策、Cookie / 同意管理按目标地区适用要求实施。

### 10.3 法务/信息说明

- 隐私政策：解释数据收集、分析、广告和相关第三方服务。
- 免责声明：说明工具信息可能变化、本站与第三方的独立关系以及联盟关系。
- 联系我们：提供可用联系渠道。
- 友情链接：由站方编辑筛选相关站点，避免无价值的大规模互链。

## 12. V3.0 验收标准

- [ ] 首页展示 ggeo.ai Logo、`All Tools`、`Submit`、`EN / 中文`。
- [ ] 顶部 8 个分类桌面端单行显示，移动端可横向滚动。
- [ ] 点击分类入口后能定位对应区域；`View All` 可进入分类详情页。
- [ ] 每个工具卡片包含名称、简介、标签、价格模式及详情入口。
- [ ] 首页工具区按分类纵向排列，不出现排行榜、AI 新闻或大型 SaaS 仪表盘。
- [ ] 搜索功能可使用，空结果有明确提示。
- [ ] 英文与中文的主要页面具备独立 URL 与正确语言内容。
- [ ] 页脚的 Privacy Policy、Disclaimer、Contact Us、Partner Links 均可访问。
- [ ] 页面按确认的深色专业视觉风格实现，桌面与移动端无明显溢出。
- [ ] 所有上线工具均有真实官网且基础资料经过核验。
- [ ] 不展示编造的评分、用户数、价格或排行榜增长值。
- [ ] 广告/赞助标识清楚，联盟链接有适当披露。
- [ ] sitemap、robots、canonical、hreflang、基础结构化数据等完成检查。
- [ ] 首页核心目录内容无需用户交互即可被搜索引擎抓取。

## 13. 本期明确不做

- 不做通用 AI 工具大全。
- 不做 AI 新闻资讯、独立榜单展示模块或社区论坛首页。
- 不做自研 AI 搜索曝光监控 SaaS 或付费 Dashboard。
- 不做无来源评分、虚构工具、伪造统计数据。
- 不批量建设没有独特内容的 SEO 着陆页。
- 不依赖复杂动态效果牺牲网页加载速度和可访问性。
