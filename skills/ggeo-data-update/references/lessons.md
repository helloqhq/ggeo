### L-01 WebFetch 截断或混入样式时改读本地保存源
- 症状：WebFetch 返回在 50,000 UTF-16 单位处截断，或正文被大段 CSS/JS 污染，关键定价表、FAQ 不在返回内容里。
- 根因：工具对可读化输出设上限；营销页内联样式脚本体积大，挤占正文配额。
- 修复／预防：不重复抓取同一 URL；直接 Read/Grep 返回末尾「Local page source」给出的完整本地源文件，按标题行号定位段落。注意临时文件约 7 天后可能清理，缺失时才重抓。第五轮多个产品、定价与法律页再次出现截断，按此读取本地完整源后完成核验。第六轮 Surva、Maya、GMBapi 等页面再次出现截断或污染，同样先读本地完整源；同一 URL 的 WebFetch 失败不反复重试，改用浏览器或既有完整源。

### L-05 推送瞬时网络失败改用 HTTP/1.1 重试
- 症状：`git push origin main` 报 `Recv failure: Operation timed out`、`Empty reply from server` 或 HTTP2 framing 错误，或长时间挂起无输出；仓库与权限实际正常。
- 根因：到 GitHub 的网络链路瞬时故障（HTTP/2 连接不稳定），非数据或权限问题；第九、十、十一轮发布阶段均出现。
- 修复／预防：失败后用 `git -c http.version=HTTP/1.1 push origin main` 重试；同轮后续推送可直接用 HTTP/1.1（第十一轮文档推送一次成功）。输出中 `credential-manager 不是一个 git 命令` 警告与成败无关，以出现 `<旧>..<新> main -> main` 行判定成功。重试两次仍失败则停止并报告，不盲目循环。

### L-07 WebFetch 正文不全时改用 curl 完整 Chrome UA 取原始 HTML

### L-09 ego-browser 任务空间收尾用 finish({keep:[]})，keep 不接受 false
- 症状：`task.finish({keep:false})` 抛 TypeError（keep 须为 "all" 或非空标签数组）；脚本间 JS 变量不共享。
- 根因：ego lite API 约定 keep 为 "all" 或 Page 标签数组；任务空间/标签跨调用持久，但脚本变量不持久。
- 修复／预防：收尾先 `await page.close()` 再单独脚本 `await task.finish({keep:[]})`；跨调用用 `taskSpace(<spaceId>)` 恢复并 `(await task.pages())[0]` 取回标签；导航与测量拆成两次调用，evaluate 内不要触发 location.href 跳转。Page 没有 `getByText`/`goBack`，点击用 evaluate 内 `el.click()`；evaluate 回调不能引用 Node 变量，需作为第二参数传入；慢站 `page.goto` 超时但「navigation committed」时直接继续读取，不重开空间。第三轮 guzu.ai 首页 20 秒超时后同为 committed，继续读取成功；任务空间若在两次校验之间被回收，用同一目标名重新 `taskSpace()` 建空间即可，不要卡在旧 id 上重试。Gmail 等 SPA 的 `goto` 与 `reload` 等待 load 均会超时，重载超时后标题已更新、snapshot 即可读到邮件正文，不必反复重试导航。Gmail 的「View entire message」会在受管弹窗中打开独立文档，原页面的 `waitForFunction` 可能超时；直接检查 `task.page("p2")` 的标题与正文即可，读完关闭该弹窗。第六轮旧 TaskSpace 被回收后按同一目标名新建空间并记录新 ID；移动端截图前若用默认 `scrollIntoView`，平滑滚动会让截图仍停在页首，应传 `behavior: "instant"`、等待 `scrollY` 达到目标，并先处理遮挡的 Cookie banner。2026-11-28 轮中文清理后的两张移动端截图再次遇到默认滚动停页首；既然 DOM 已确认对比容器和滚动能力，最终未重复消耗时间截图，改用 DOM 几何检查完成复核。

### L-12 定价页默认展示年付折算价，需切到月付再读
- 症状：Honeyb 定价页默认勾选 Annual，卡片显示 $23/$63/$159「每月」并注明每年账单，直接读取会把年付折算价当成标准月价；切到 Monthly 后为 $29/$79/$199。SEOcrawl 定价页另有币种选择器，切换后金额随之变化。
- 根因：定价组件把折扣周期设为默认视图，折算月价与标准月价只差一个开关；币种选择器会改变显示金额而非套餐内容。
- 修复／预防：读取定价页时先确认当前计费周期与币种标签，必要时点击月付/年付或币种切换后再提取；记录标准月价、年付折算月价与实际年账单分别是什么，促销折扣单独注明期限与性质。切换后重新读取卡片文本，不复用切换前的数值。注意反向陷阱（Geoptie 2026-11-23）：静态 HTML 显示的价格与页面上「Pay annually」标注不一定同属一个计费周期，选中态是 JS 组件状态，先在真实浏览器确认当前勾选的是月付还是年付再取数。另有两种非周期证据：Pixis 的 credits 每月更新不等于 $100/$400 标价按月收费；Moz 的首年 $950/$1,719/$2,868 不是永久年价，VisibAI 的“付 10 个月得 12 个月”也未公布年度总额，均不得推算。RecoRadar 的创始折扣与 Black Friday 首付折扣均标为临时促销，不替换标准套餐价格。2026-11-28 轮 SoRank 切到 Monthly 后，套餐卡片显示促销价而详细对比表仍显示另一组金额；切换动作成功不等于两个区域同步，必须分别提取。MentionedOn 页面只显示 `$`，通过官方 JSON-LD 的 `priceCurrency: "USD"` 确认币种；SoRank 同样由 JSON-LD 确认 USD。

### L-13 新工具部署后站内搜索受索引缓存影响
- 症状：详情页已返回 200，线上 `/assets/directory.json` 已含新条目，但用户搜索新工具名暂时无结果；过几分钟自行恢复。
- 根因：搜索在浏览器端读取 `/assets/directory.json`，GitHub Pages 对该文件返回 `cache-control: max-age=600`；部署前访问过的浏览器或已打开的页面继续使用旧索引。
- 修复／预防：索引请求使用 `fetch(..., {cache: 'no-cache'})`，按 ETag 每次重新验证；部署后核验搜索时用真实浏览器或 `cache: no-store` 请求，不把缓存滞后误判为数据或匹配缺陷。已打开的旧页面刷新一次即可。

### L-10 法律页存在性以读到的条款正文判定
- 症状：Sellm 的 /terms、/privacy 对 curl 返回 200，但真实浏览器渲染为 404；GEOBase 法律页在浏览器报客户端 500，curl 的服务端 HTML 却含完整协议正文。
